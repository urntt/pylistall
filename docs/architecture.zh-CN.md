## 模块与数据流

| 模块 | 职责 |
| --- | --- |
| `cli.py` | 参数验证、单次收集编排与独立目的地交付 |
| `patterns.py` | 默认排除、模式规范化、名称及目标子树匹配 |
| `traversal.py` | 迭代扫描、提前剪枝、私有 Git 入口、链接循环与诊断 |
| `tree.py` | 名称筛选后的树和连接祖先，不读取内容 |
| `selection.py` | 元数据候选、单次二进制分类、结构化分块读取 |
| `names.py` | 控制字符可见展示、行内代码定界符与项目名 |
| `gitlog.py` | 消费私有 Git 入口并分块读取子进程输出 |
| `output.py` | 结构化模型、语言标识、Markdown 与精确预算 |
| `progress.py` | 独立且可选的 Rich 收集反馈 |
| `destinations.py` | 文件目的地与安全写入 |
| `viewer.py` | 直接消费模型的字面量终端渲染与分页 |
| `util.py` | 平台剪贴板传输 |

```text
参数 -> 共享模式 -> 一次遍历（排除剪枝）
                     |-> 树名称视图（包含与连接祖先）
                     |-> 私有 Git 入口 -> Git 分块读取
                     |-> 元数据候选 -> 分类 -> 分块读取
        可选回调 -> stderr 进度
        cli -> 项目 + path/tree + Git + Files -> 模型 / Markdown 预算
        清理进度 -> 警告 -> 摘要或展示／文件／复制
```

结果仍在内存组装。独立收集器复用扫描器。只有标题或标题加 path 时验证根目录，
但不枚举目录、不检测内容、不查询 Git。

## 遍历、过滤与链接

显式解析后的根目录本身豁免包含与排除，规则从子项开始。通过平台 `fnmatch`
匹配名称和以 `/` 分隔的逻辑相对路径；重复及逗号分隔规则去空白、空项并去重。
只有裸 `-o` 启用默认集，混用时取并集；默认 `**/` 规则派生根层规则，自定义规则不派生。
`*.py` 可匹配任意层级名称，`src/*.py` 可匹配更深路径；这不是 Git ignore 语法。

先检查逻辑排除再检查目标。目录名称、相对路径或相对路径加 `/` 命中时提前剪枝。
`src/**`、`src/` 剪掉 `src`，`src/*.py` 不剪掉父目录。被排除节点本身计入已发现，
未访问后代不计。没有排除规则时 `.git` 不会被永久隐藏。

包含仅筛选文件叶节点及连接祖先，不缩小扫描范围、不授权二进制。未启用包含时保留
全部未排除结构。树排序为目录优先，名称大小写不敏感再以原名称破同序；Files 按逻辑
相对路径使用相同大小写排序。树不受内容可读性或二进制权限影响。

链接默认标记 `@`，只检查链接元数据，不读取目标；识别 junction，但不把所有 Windows
reparse point 当链接。未跟随、断链及无法检查的条目按逻辑名称筛选树。`-l` 允许根内外
目标，目录展开仍需 `-r`。真实目录身份按当前祖先链检测循环，非循环别名分别保留。
跟随时对解析目标及被排除的目录祖先继续匹配，相对收集根目录，跨盘使用绝对路径，
防止文件别名绕过目录排除。显式传入根目录链接即使没有 `-l` 也会解析。

## 内容与编码

候选是通过名称、链接可读目标和输出身份排除后的普通文件，统计在二进制判断之前。
输出目标及符号／硬链接别名仅排除正文，树可保留已有名称。禁用 Files 不采样、不读取。

保留扩展名、NUL、增量 UTF-8 和非文本字节比例启发式。文本正常展开；二进制必须由
裸 `-b` 或匹配的权限规则授权。`-i` 不授予权限，`-b` 不增加候选。未展开二进制保留标题
和占位说明。内容块显式区分 `None`（未展开）与 `""`（成功读取空内容），记录编码、截断
和错误，不从字符串提示推断状态。

单一分块读取器返回明确结果。文本使用 UTF-8 替换解码、LF 转换和原有正文内截断标记。
二进制使用标准 Base64，跨块保留三字节分组余量、带填充、不插入换行。`-m` 先限制原始
字节再编码；前缀可正确解码，截断标记在围栏外。失败是可见错误块，不编码错误文字。
不解压、不解释文件格式、不识别图片。

## Git 日志

同一次扫描在已访问且未剪枝目录中私有记录 `.git` 目录和普通 worktree 指针。
显式 Git 收集允许检查被排除的 `.git` 元数据，但不展示或展开被排除目录；
完整排除的父目录内不再查找。包含与二进制权限不限制 Git 发现。
非递归只检查根层；递归允许嵌套仓库，链接入口遵循相同链接策略。
按解析后的绝对 `.git` 路径排序，执行 `git -C <parent> log --oneline --decorate --no-color`，
可限制数量。无仓库、空日志与失败保留原有标记。未请求 `-g` 或禁用 Git 不启动 Git。

## 输出与剪贴板

`OutputDocument` 始终包含 `project_name`，`path/tree/git/files` 可选。
全部部分均可禁用；旧 disable 名称 `root` 返回参数错误。项目名取解析根目录名称，
系统根使用 `/`、Windows 盘符锚点或 UNC 共享名。Markdown 依次为动态行内代码项目标题、
合并的 `bash` 路径／树代码块、可选 `## Git log`、`## Files`。
启用的空树显示 `(empty)`；Files 启用时保留章节，无候选显示 `[No files selected]`。
Git／文件子标题用行内代码，普通字符不转义，控制字符显示可见转义；定界符长于名称
中的反引号串，必要时填充空格。正文围栏至少三反引号并避开冲突。Base64 有编码说明。
章节统一空行，最终正文 LF 结尾。

`MarkdownBuilder` 计算最终 UTF-8 字节，含标题、标签、动态围栏及截断。
文件、Base64 与 Git 分块检查保守下界，再对完整块精确计量。超限停止后续处理，
关闭文件并终止、等待、关闭 Git；任何目的地都不收到部分正文。
dry-run 使用相同收集与计量，仅报告计数、大小和目的地。

Rich 直接消费模型，不解析 Markdown、不重读文件，复用语言标识；缺失时静默回退。
重定向输出无 ANSI Markdown。分页要求 stdin/stdout 为终端，遵循 `-n/PAGER`；less
使用 `-FRX` 和 UTF-8，more 使用无颜色的平台编码。启动失败直接展示；正常退出分页器
及下游关闭管道返回 0。

文件目的地从命令执行目录计算，名称每次仅计算一次本地时间，支持 `~`、自定义名称，
没有 `-w` 时拒绝碰撞。完整收集与预算成功后才创建父目录并写 UTF-8／无 BOM／LF。
独占创建清理失败文件；覆盖先完成同目录临时文件再替换原文件。目的地失败返回 1，
报告已完成操作而不回滚它们。只有 `-c` 使用剪贴板：macOS UTF-8 pbcopy、Windows
UTF-16LE clip、Linux UTF-8 xclip 或 pyperclip。

## 进度与取消

stderr 为 TTY、TERM 不为 dumb 且未设置 `-P` 时启用；stdout 重定向或 `-f/-c/-D`
不单独关闭。延迟导入 Rich，扫描、树、Git 用转圈且不虚构百分比，Files 显示已检查／候选
和实际收集数。字面量路径按宽度裁剪，最多 10 Hz；关闭 Rich 对业务流的重定向。
可选回调复用已有索引与分类，不额外扫描、采样或读取。UI 失败仅关闭反馈。
警告、摘要、正文或分页前清理进度。

- 已发现：枚举到的逻辑子项，含被排除节点，不含根及未访问后代。
- 候选：二进制判断前，通过名称、链接和输出身份筛选的普通文件。
- 已检查：处理完的候选，含占位与失败。
- 实际收集：成功取得的正文，含空文件和受限前缀。

别名分别计数。摘要 `files` 表示 Files 条目，`collected` 另报读取成功数。
参数／根目录错误返回 2，预算／目的地失败返回 1，Ctrl+C 返回 130 且无 traceback。
取消清理反馈、读取器、Git 和不完整写入，保护已有文件。普通内容失败继续生成错误块。

## 安全边界与当前限制

本地收集，不上传、不执行代码；显式复制替换剪贴板，`-w` 允许文件替换。
默认名单不是秘密检测，会排除部分样例与公开证书，不加载 `.gitignore`。
跟随可读取根外目标，worktree 可引用外部元数据。扫描不是原子快照，不能防止并发替换。
Base64 增大体积，不压缩、不解释文件。`-M` 限制 Markdown，不限制总内存或目录索引，
默认不限。Git 没有运行超时。安全写入依赖文件系统语义。
模拟测试不能作为真实终端和剪贴板集成验收。
