## 模块与数据流

| 模块 | 职责 |
| --- | --- |
| `cli.py` | 验证参数、收集一次并交付 `OutputResult` |
| `traversal.py` | 迭代遍历、链接识别、祖先循环检测与诊断 |
| `tree.py` | 渲染共享条目，独立于内容过滤 |
| `selection.py` | 规范化模式、筛选、识别及读取文件 |
| `gitlog.py` | 从共享条目查找仓库并收集 Git 日志 |
| `output.py` | 结构化模型、Markdown 与总量预算 |
| `destinations.py` | 文件路径与安全写入 |
| `viewer.py` | Rich 字面量展示及分页传输 |
| `util.py` | 平台剪贴板传输 |

```text
参数 -> cli -> traversal：共享遍历索引
                |-> tree：排序并渲染
                |-> gitlog（可选）：查找 .git -> Git -> 分组
                |-> selection：筛选 -> 采样 -> 读取 -> 渲染
           cli：根路径 + 目录树 + Git + 文件
                -> Markdown 展示／文件／可选复制 -> stderr 状态
```

独立调用收集函数也使用同一个扫描器。内容排除保留目录树名称，不过滤 Git 查找。
结果仍在内存中组装。

## 目录树

显式栈对每个展开的逻辑目录扫描一次，渲染也使用栈。目录优先，名称按大小写不敏感
顺序排序，再用原始名称处理同序。`-r` 控制展开，内容过滤不隐藏名称。链接标记 `@`，
默认不检查目标、不读取或展开；仅符号链接和 junction 的 reparse tag 视为链接，
不把所有 Windows reparse point（例如云文件）都当作链接。

`-l` 允许根内及根外的文件和目录目标，目录展开仍需 `-r`。真实目录身份与当前祖先链
比较，停止循环，保留非循环的重复别名。显式根目录即使没有 `-l` 也会解析。
跟随后的断链和无法访问的嵌套条目保留名称并警告；根目录枚举失败为致命错误。

## 内容筛选与读取

共享索引中的普通文件才是候选；特殊文件不会打开。`fnmatch` 匹配名称和 `/` 分隔的
逻辑相对路径。重复和逗号分隔的模式去除空白及空项，大小写规范化遵循平台行为，
不是 Git ignore 语法。

包含规则限制候选；排除优先于包含与二进制策略，同时检查逻辑路径和解析目标名称、
路径。裸 `-o` 才启用根层及嵌套默认集；自定义模式保留普通 `fnmatch` 行为，不自动
启用默认集。缓存、生成文件和敏感名称类别见 [README](../README.zh-CN.md)。程序
不加载 `.gitignore`，业务日志和依赖锁文件保留。

二进制识别先检查扩展名，再读取有限样本和前瞻字节。NUL 表示二进制；严格增量 UTF-8
解码允许采样边界截断字符，但检查文件末尾；失败后使用非文本字节比例启发式。
无法采样时按二进制处理。显式包含可强制包含，否则必须由 `-b` 允许。此启发式不能
验证整个文件。

选中文件按逻辑显示路径排序，以 UTF-8 替换解码。单文件上限使用前瞻字节判断并添加
`[...TRUNCATED...]`；错误形成 `[Failed to read file: ...]` 内容块。二进制包含不会
解压或解释图片、文档。

## Git 日志

共享条目识别 `.git` 目录和普通 worktree 指针文件，链接 `.git` 需 `-l`。非递归时
仅查找根层。分组按绝对路径排序，运行 `git -C <parent> log --oneline --decorate`，
可限制数量。嵌套遍历失败不丢弃已发现的仓库；无仓库、空日志与子进程失败有明确标记。
请求日志时需要 PATH 中的 Git，不使用 Git Python 库。

## 输出、预算与目的地

`OutputDocument` 保存可选根路径、目录树、Git 与文件 `ContentBlock`、警告及跳过数。
`output.py` 统一语言识别、路径转义和围栏格式；围栏至少三个反引号且长于内容中的
反引号串。Markdown 根路径为首行，树、Git、文件有分组标题，路径使用子标题。
内容转换为 LF，不增加代码行号；所有目的地复用同一结果，不重新读取文件。

`MarkdownBuilder` 按规范格式累计 UTF-8 字节。文件及 Git 分块解码，每块检查保守
下界，完整内容再按实际动态围栏精确检查。超限立即中止，Git 子进程会 kill、wait 并
关闭管道；任何正文、复制或写入都在完整预算成功之后。默认总量不限。
`-d files` 避免采样和读取，`-d git` 避免调用 Git；`-D` 准确收集后只向 stderr
报告大小、跳过数与目的地，不创建目录、写文件或复制。

默认在 TTY 使用 Rich，重定向使用 Markdown；`-c` 额外复制 Markdown，`-f` 不展示正文。
`viewer.py` 使用同一模型与语言标签，延迟导入 Rich，ImportError 静默回退。Text/Syntax
按字面量展示，不增加行号或围栏。分页要求两个流都是终端，遵循 `-n` 与 `PAGER`；
Less 使用 `-FRX` 和 UTF-8，系统 more 使用无颜色的平台编码。启动失败直接展示，
正常退出及下游关闭管道不会产生 traceback。
`destinations.py` 每次命令计算
一次本地时间名称，从命令执行目录解析相对路径，收集前排除目标及符号／硬链接别名。
非覆盖使用独占创建并清理失败文件；覆盖先写同目录临时文件再替换，保留原文件。
UTF-8、无 BOM、LF。收集和预算成功后才创建父目录，已有目录不能覆盖为文件。
每个目的地独立报告已完成操作，某个失败返回 1，提示全部写 stderr。

剪贴板仅在 `-c` 使用：macOS UTF-8 `pbcopy`、Windows UTF-16LE `clip`、Linux UTF-8
`xclip -selection clipboard` 或 pyperclip。参数／根路径错误为 2，交付或预算失败为 1，
下游关闭管道正常退出。移除 `-p` 的迁移见 [README](../README.zh-CN.md#从-031-迁移)。

## 安全边界与当前限制

收集在本地完成，不上传数据，不执行收集代码。复制替换剪贴板；保存可在显式 `-w`
时替换文件。默认展示及文件导出无需桌面会话，测试仍模拟剪贴板。

- 裸 `-o` 是名称排除而非秘密检测，会排除部分样例、公开证书；树名称仍可见。
- 默认跳过链接；`-l` 允许根外目标。worktree 指针可能引用外部 Git 元数据。
  遍历不是原子快照，不能防止并发路径替换。
- `-M` 限制最终 Markdown，不限制共享目录索引或总内存；默认不限，`-m` 仅限制文件。
- 未限制 Git 运行时间；无法访问的文件以错误标记呈现。文件系统并发变化可导致预览
  与后续独立命令不同。临时文件写入和替换依赖本地文件系统语义。
